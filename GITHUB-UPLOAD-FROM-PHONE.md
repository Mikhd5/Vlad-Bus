# Завантаження проєкту на GitHub з телефону

## Важливо
GitHub і Vercel не розпаковують ZIP як вихідний код проєкту. Спочатку розпакуйте архів на телефоні, а потім завантажте **вміст папки проєкту** до кореня репозиторію. Не завантажуйте лише ZIP-файл.

## 1. Розпакуйте архів

- **iPhone:** відкрийте застосунок «Файли», знайдіть ZIP та торкніться його один раз. iOS створить папку з файлами.
- **Android:** відкрийте ZIP у «Файлах» / Files by Google та виберіть «Розпакувати».

## 2. Завантажте файли до GitHub

1. Відкрийте GitHub у браузері та перейдіть до потрібного репозиторію.
2. Відкрийте корінь репозиторію (там, де має лежати `index.html`).
3. Натисніть **Add file → Upload files**.
4. Виберіть файли та папки з розпакованого проєкту. Якщо мобільний браузер не дозволяє вибрати папки, увімкніть «Версія для комп’ютера» або завантажуйте вміст папок окремими партіями, зберігаючи структуру.
5. Переконайтеся, що `index.html`, `package.json`, `vercel.json`, папки `api`, `assets`, `crm`, `supabase` та файли `script.js`, `styles.css` опинилися безпосередньо в корені репозиторію.
6. Унизу натисніть **Commit changes**.

## 3. Підключіть Vercel

1. Увійдіть у Vercel.
2. Натисніть **Add New → Project** та імпортуйте GitHub-репозиторій.
3. Framework Preset: **Other**.
4. Root Directory: `./` (корінь репозиторію).
5. Build Command можна залишити порожнім; Output Directory також не задавайте.
6. Натисніть **Deploy**.

Після деплою:
- сайт: `https://ВАШ-ДОМЕН/`
- CRM: `https://ВАШ-ДОМЕН/crm/`
- демо-вхід до CRM: логін `test`, пароль `test`.

## 4. Що працює без додаткових ключів

- Публічний сайт та адаптивна верстка.
- Форма заявки готує повідомлення та відкриває WhatsApp на номер перевізника.
- Демо-режим CRM з тестовими записами та локальним збереженням у браузері.

## 5. Що потребує окремого налаштування

Для спільної бази між різними пристроями та командою потрібно створити Supabase-проєкт, виконати `supabase/schema.sql` і додати серверні змінні у Vercel. Інструкція є у `README.md`, приклад змінних — у `.env.example`.

**Безпека:** ніколи не завантажуйте `.env.local`, `.env` або service-role/secret key у GitHub. У репозиторії має бути лише `.env.example` із порожніми/прикладними значеннями.
