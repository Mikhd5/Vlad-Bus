# Україна — Європа | Сайт та CRM

Єдиний проєкт для Vercel: публічний сайт у корені репозиторію, CRM у `/crm/`, серверні функції у `/api/`.

## Адреси

- Сайт: `/`
- CRM: `/crm/`
- API конфігурації: `/api/config`
- API маршрутів: `/api/routes`
- API бронювань: `/api/bookings` (підготовлений для майбутнього підключення; публічна форма наразі надсилає заявку через WhatsApp).

## Демо-доступ до CRM

- Логін: `test`
- Пароль: `test`

Без налаштованого Supabase CRM відкривається в локальному демо-режимі. Дані демо зберігаються у браузері на поточному пристрої й не синхронізуються між пристроями.

## Функціональність

### Сайт
- Адаптивна головна сторінка міжнародного перевізника.
- Напрямки: Молдова (аеропорт Кишинів), Бельгія, Нідерланди, Польща, Австрія, Чехія, Швейцарія, Данія та Німеччина.
- Транспорт, переваги, інформація про перевізника та контакти.
- Форма заявки з маршрутом, датою, часом, пасажирами та контактами.
- Після відправлення відкривається WhatsApp із підготовленим повідомленням на номер +380 97 932 79 77. Клієнт перевіряє та сам надсилає повідомлення менеджеру.

### CRM
- Огляд та показники.
- Бронювання, статуси, призначення рейсу, оплати, примітки й експорт CSV.
- Фінанси та журнал платежів.
- Рейси, маршрути й розклад.
- Клієнти, транспорт і водії.
- Демонстраційні записи можна створювати, змінювати й видаляти локально.

## Структура репозиторію

```text
/
├── index.html              # публічний сайт
├── styles.css
├── script.js
├── crm/
│   ├── index.html          # CRM
│   ├── crm.css
│   └── app.js
├── api/
│   ├── config.js
│   ├── routes.js
│   └── bookings.js
├── assets-at-root:
│   ├── cheetah-mark.png
│   ├── destinations-poster.webp
│   ├── fleet-poster.webp
│   ├── routes-panorama.webp
│   └── favicon.svg
├── package.json
└── vercel.json
```

Зображення зберігаються в корені репозиторію, тому сторінка звертається до них через абсолютні шляхи, наприклад `/fleet-poster.webp`.

## Деплой на Vercel

1. Імпортуйте цей репозиторій у Vercel.
2. Framework Preset: Other.
3. Root Directory: `.` (корінь репозиторію).
4. Build Command: залишити порожнім / Override вимкнути.
5. Output Directory: залишити порожнім / Override вимкнути.
6. Install Command: автоматично (`npm install`).
7. Запустіть Deploy.

`vercel.json` налаштовує серверні функції у `api/*.js` та заголовки безпеки для CRM/API. Не змінюйте Root Directory на `crm` або `api`.

## Supabase та спільна база

Поточний демо-режим CRM не потребує Supabase. Щоб згодом увімкнути спільні облікові записи та синхронізацію, потрібно створити Supabase-проєкт, додати серверні змінні середовища у Vercel і виконати SQL-схему бази даних. До налаштування цього кроку не вводьте реальні дані клієнтів у демо-CRM.

Секретний ключ Supabase зберігайте тільки у Vercel Environment Variables. Ніколи не додавайте service-role/secret key до HTML, клієнтського JavaScript або відкритого GitHub.

## Перевірка коду

За наявності Node.js виконайте:

```bash
npm install
npm run check
```

Для локального запуску з Vercel CLI:

```bash
npm run dev
```
